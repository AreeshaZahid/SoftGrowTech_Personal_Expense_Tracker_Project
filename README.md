# Personal Expense Tracker

A simple and powerful Python-based Personal Expense Tracker that helps users manage daily income and expenses efficiently.

# Features

- Add Income
- Add Expenses
- View All Transactions
- Monthly Financial Summary
- Category-wise Expense Report
- Search Transactions
- Delete Transactions
- Export Data to CSV
- SQLite Database Storage
- Automatic Balance Calculation
- User-friendly Menu Interface

# Technologies Used

- Python 3
- SQLite3
- CSV Module

# Input Details

## Category

Type of transaction.

### Expense Categories
- Food
- Shopping
- Bills
- Rent
- Education
- Medical

### Income Categories
- Salary
- Business
- Freelancing
- Bonus

## Amount

Enter money value.

## Description

Short note about the transaction.

Example:

```text
Lunch with friends
```

---

## Date

Format:

```text
YYYY-MM-DD
```

Example:

```text
2026-05-15
```

Leave blank to use today's date automatically.

## Add Income

```text
Enter category: Salary
Enter amount: 50000
Enter description: Monthly Salary
Enter date (YYYY-MM-DD):
```
